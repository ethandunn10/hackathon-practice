# Onboarding — hackathon-practice ("Should I Recycle This?")

Repo: https://github.com/ethandunn10/hackathon-practice

## Stack
Frontend: HTML/CSS/JS. Backend: Node/Express + Anthropic Claude API. Logging: Supabase. Deployed on Vercel.

## Roles on a team like this
- **Idea/Pitch** — owns the problem framing, presents to judges, tells the story
- **Frontend** — builds/styles the screens
- **Backend/AI** — API integration, prompt logic, the data layer (this one's been me so far)
- **Design** — visual polish, UX flow

If you're joining, pick whichever's open and dive in.
